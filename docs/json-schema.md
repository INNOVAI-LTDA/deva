# JSON gerado pelo Diagnóstico DEVA

Estrutura principal:

```json
{
  "generatedAt": "ISO datetime",
  "economicInputs": {},
  "economicMetrics": {},
  "devaAnswers": {},
  "devaMetrics": {},
  "interpretation": {}
}
```

## economicInputs

Valores informados pelo usuário.

## economicMetrics

Métricas calculadas a partir dos dados econômicos.

## devaAnswers

Respostas dos sliders.

## devaMetrics

Métricas geométricas e índices do DEVA.

## interpretation

Cenário, pontos de atenção e ações diretas.
```
